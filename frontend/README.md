# WishCatcher Frontend

Frontend Next.js pentru WishCatcher + Astra Genesis

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Aplicația va rula pe `http://localhost:3000`

## Environment Variables

Creează `.env.local`:

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## Features

- ✅ Dashboard cu wish-uri
- ✅ Filtre geografice/culturale
- ✅ Wish detail cu trigger analysis
- ✅ Business plan generation
- ✅ MVP structure generation
- ✅ Download MVP
