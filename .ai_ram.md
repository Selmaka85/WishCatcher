## PROJECT
WishCatcher detects real, often unexpressed human needs in wide public
conversational contexts and feeds validated, evidence-backed opportunities into
the ASTRA Genesis structural solution composer. NOT an advertising system.
ASTRA Genesis original doctrine: intent -> logical component combinations ->
scoring -> feasible structures/executable prototypes across domains.

## TECHNICAL DECISIONS
- Never discard a thread as vague until multi-message context is evaluated.
- Preserve original author identity and comment parent/chronology.
- Separate other speakers' needs from original speaker's wish.
- Distinguish explicit statements, inferred needs and unknown.
- Ground in source-message IDs; no invented willingness to pay.
- Keep existing detectors; integrate, don't duplicate their business roles.
- LLM disabled by default, no paid inference/no external data transfer
  without explicit environment configuration.
- Existing market validation/scoring and downstream API remain available.

## PLUGIN ADAPTERS / LOCAL KNOWLEDGE (2026-11-03)
- `backend/app/wishcatcher/integrations/plugin_runtime.py` owns `WishCatcherPlugin`:
  a re-usable, provider-neutral Python entrypoint (not tied to Reddit or a model).
- `OpenAICompatibleContextInterpreter` supports Ollama/LM Studio local endpoints
  or OpenAI-compatible remote chat APIs, opt-in only. Provider model quality untested.
- `SQLiteGraphRAG` provides local persistent SQLite FTS5 keyword retrieval plus
  typed document-edge expansion. This is graph-assisted RAG, NOT vector semantic
  embeddings, embedding GraphRAG or an LLM memory guarantee.
- `BraveWebSearch` and `MCPResearchBridge` are opt-in RESEARCH tools.
  MCP uses optional official 2026 Python SDK and explicit search-tool allowlist,
  does NOT autonomously execute arbitrary tools or launch processes.
- `backend/app/api/routes/context_plugin.py` exposes token-protected
  POST /api/context/analyze, /knowledge, /knowledge/link for external applications.
  Missing WISHCATCHER_PLUGIN_ACCESS_TOKEN fails closed (503).
- Memory retention is explicitly opt-in (`remember=True`), stores reduced need summaries under hashed keys with domain graph links; never archives full discussions by default.
- Plugin retrieval/research results are kept separate from speaker-grounded evidence
  and never auto-promoted to a verified customer statement.
- `docs/PLUGIN_RUNTIME.md` documents environment variables, examples,
  provider connectors, integration boundaries and remaining scientific gates.
- `tests/test_plugin_runtime.py` covers local GraphRAG, controlled
  research execution, and no-network defaults. First CI run exposed a
  cross-language FTS lookup mismatch; repair queries using normalized domain.
  GitHub Actions run 41732648603 reported SUCCESS (21 tests at that SHA).
- TODO: contract tests across the actual FastAPI route and existing
  scraper/storage/Genesis consumers; live local LLM and live search/MCP
  evaluations are not yet verified. Do not claim end-to-end production success.
